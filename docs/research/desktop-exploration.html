Delivered feature and verification

apps/desktop/scripts/explore/inspect.mjs saves exact JSON, status, coverage summary and optional window PNG into a new local directory. probe.mjs requires explicit input permission and a ref from that capture, saves a single action report, then re-reads the same window. Neither retries input. Each capture gets a separate driver session.

fixture.ps1 and the adjacent README reproduce the demo. Package commands are explore, explore:probe and test:explore. Seven Node tests pass, including partial coverage, image pinning, overwrite refusal, input gating, uncertain delivery and malformed process output.

Run from the repository root:

node --test apps/desktop/scripts/explore/explore.node-test.mjs
node apps/desktop/scripts/explore/inspect.mjs --app APP --out NEW_DIRECTORY --screenshot

Scope: local exploration, with an external executable and bounded process output. Linux/macOS execution, CUA parity, authenticated app capture and packaged installation remain unverified. Ruth, hosted transport and Electron IPC are unchanged. A future integration must route authenticated device-bound tool calls to desktop main, preserve consent and delivery uncertainty, and explicitly attach image content to the AI SDK response.
