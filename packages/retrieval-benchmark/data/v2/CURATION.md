# Retrieval benchmark v2 extension curation

Dataset version: `v2-extension-0.2` (schema version 1).

## Validation summary

- Exact-value: 44 queries, 22 development / 22 test. After collapsing whitespace and case-folding, every needle occurs in exactly one artifact, which matches its evidence artifact. Each needle contains the answer-bearing span.
- Unanswerable: 30 questions, 15 development / 15 test. SQL `ILIKE` searched each distinctive target phrase across all non-outline chunks scoped to `user_id = 'bench-v1'` in the configured `avenire_rag_dev` database; every query returned zero rows. Closest chunks were read in context and do not state the requested details.
- Timestamp: 20 questions, 10 development / 10 test. Every SRT window was read; locator bounds match the caption cues used.
- Referential integrity: every required evidence ID exists and every evidence row has a grade-3 judgment. Unanswerable queries intentionally have no evidence or judgments.
- Only `packages/retrieval-benchmark/data/v2/extension.json` and this notes file were edited. No code was edited and no commit was made.
