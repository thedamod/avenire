Entropy and the second law
Written overnight from 3 sources · accepted 6:02 AM
Entropy counts how many microscopic arrangements match what you can observe. For an isolated system it never decreases: it stays constant for a reversible process and grows for every real one.

Entropy, explained · 18:40
dS ≥ δQ / T
The Clausius inequality makes this measurable: around any cycle ∮ δQ/T ≤ 0, with equality only when every step is reversible. That is why no engine beats the Carnot efficiency.
