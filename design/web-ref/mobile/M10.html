What entropy measures
Entropy counts how many microscopic arrangements are consistent with what you can observe. A gas spread through a box has vastly more arrangements than the same gas packed in a corner, which is why it spreads and never gathers back.
• State function: ΔS depends only on the start and end states, so you can compute it along any reversible path.
• Second law: for an isolated system, ΔS ≥ 0. Use dS ≥ δQ/T for anything else.
